# Contributing to PointCloudsVR

Thank you for your interest in contributing to PointCloudsVR!

This project is maintained by the team at NASA Goddard Space Flight Center and welcomes contributions from the open-source community.

## Getting Started

To build and run the project locally:

1. Clone the repository.
2. Follow the build instructions in the User Manual (see `/doc` folder).
3. Build using CMake on Windows with a compatible compiler (e.g., Visual Studio).
4. Install and configure SteamVR/OpenVR.

## How to Contribute

We welcome:

- Bug reports
- Feature requests
- Pull requests (bug fixes, documentation improvements, new features)

Before opening a pull request:

- Create a new branch based on `main`.
- Make sure your code builds and runs without errors.
- Add a clear and concise description of your changes.
- If relevant, update or add documentation.

## Code Style

Please follow the existing formatting and naming conventions in the codebase. We're gradually working toward standardizing CMake and C++ style.

## Questions or Help

If you have any questions, feel free to open an issue or contact the maintainers listed in the `README.md`.
